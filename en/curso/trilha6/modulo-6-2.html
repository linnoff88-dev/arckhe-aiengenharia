Putting it all together: the 6 layers in action

Prompt → Intention → Context → Leverage → Architecture → Evolution

🔗 How each layer feeds the next

Prompt (T1): without a structured request, even the best intention doesn't translate into a result.

Intent (T2): without a clear destination, you write precise prompts for the wrong place.

Context (T3): without the full picture, even the right intention produces a generic response.

Effective use (T4): without a method, a good result gets stuck in a conversation and never becomes an asset.

Architecture (T5): without structure, the method doesn't scale beyond you.

Evolution (T6): without the improvement cycle, the system grows and stops. With it, each cycle starts stronger than the last.

Review rhythms without bureaucracy

Lightweight rituals that stick—not heavyweight methodologies we abandon.

D

Daily check (2 min)

At the end of any task that used AI: “Was it better or worse than expected?” If worse: note why. If much better: note what variable was different. Nothing more than that.

S

Weekly check (10 min)

What worked this week? What would you repeat? What would you adjust? Is there an artifact worth updating based on what happened? If so—update it now.

M

Monthly review (30 min)

Full audit: check progress indicators, version artifacts that have accumulated changes, review the system map, and check whether the metrics are moving in the right direction.

T

Quarterly review (1-2h)

The time to look at the system as a whole: has any artifact reached end of life and needs to be rewritten? Is any layer underdeveloped? Is it time to plan the next level?

When to rewrite vs. adjust

The end-of-life diagnosis for an artifact.

✓ Adjust (patch)

  • • The artifact’s core is still valid
  • • The change needed is specific and well-defined
  • • Fewer than 3 patches have been applied
  • • The artifact’s purpose hasn’t changed
  • • Result: add/remove an instruction

✗ Rewrite (reset)

  • • Accumulated 4+ patches that contradict each other
  • • The goal changed (new context, new audience)
  • • Results consistently below expectations
  • • You can't explain the logic behind the current artifact
  • • Result: new file, v1.0 with what you learned

🔍 The clearest sign that it’s time to rewrite

If you read the current artifact and can’t explain why each instruction is there—or worse, if some instructions seem to contradict each other—that’s a sign the artifact grew without planning and accumulated debt. Rewriting it costs 2 hours now; continuing with the bad artifact costs weeks over the course of the year.

Slow User Shortcut

The one question that triggers the evolution cycle at any point.

The question that starts everything

"What do I keep repeating that could be better?"

Apply it to any recurring task. The response points to the system’s most valuable next refinement—no meeting, no methodology, no ceremony.

✗ Without the question

  • • Repeat the same tasks with the same effort
  • • You notice it "took a long time" but don't know why
  • • Waits for a “good time” to improve the system
  • • 1 year later: same speed, same effort

✓ With the question

  • • Identify the most time-consuming recurring task
  • • Create or update the artifact for that task
  • • The next run is already better
  • • 1 year later: task takes half the original time
